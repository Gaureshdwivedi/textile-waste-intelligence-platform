# Textile Waste Intelligence Platform

## 📌 Project Overview

The Textile Waste Intelligence Platform is an AI-powered web application that helps identify textile materials, classify waste, estimate recyclability, recommend recycling strategies, and analyze sustainability metrics.

## 🚀 Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- FastAPI

### Database
- PostgreSQL

### AI & Machine Learning
- TensorFlow
- OpenCV
- EfficientNet

### Deployment
- Docker
